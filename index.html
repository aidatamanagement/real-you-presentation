Cost is engineered

  • Cost is measured by finished video, not by attempts. The system minimizes wasted generations.
  • If part of a video fails, only the missing pieces are redone, so a problem never doubles the bill.
  • A hard cap on clips per video keeps spend predictable.

Reliability is built in

  • When a provider is busy, the system waits and retries automatically, at no extra cost.
  • Multiple video providers are supported, so if one is down or degraded, generation can switch to another instead of stalling.
  • If something fails mid-video, it stops cleanly rather than producing broken output.
  • Completed work is reused, so a failure never restarts the whole job.
